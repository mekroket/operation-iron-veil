# OPERATION: IRON VEIL

A single-player military FPS that runs in a browser tab. Version 0.1 contains one mission, SILENT BREAKWATER: land on a breakwater before dawn, cross a port held by a private military contractor, copy a manifest, and get out. Every model, texture and sound is generated by code at load time. All characters, organisations, places and weapons are fictional.

**Play:** https://mekroket.github.io/operation-iron-veil/

Needs a desktop browser with WebGL2, a keyboard and a mouse.

## Controls

| Action | Input |
|---|---|
| Move | W A S D or arrow keys |
| Look | Mouse |
| Fire | Left mouse |
| Aim down sights | Right mouse |
| Reload | R |
| Sprint | Shift |
| Crouch | C or Left Ctrl |
| Jump | Space |
| Interact | E |
| Switch weapon | 1, 2, 3 or mouse wheel |
| Pause | Esc |
| Skip cinematic | Space or Enter |

## Stack

- Babylon.js 9.33.1, WebGL2 baseline, optional WebGPU with `?webgpu=1`
- Havok physics (WebAssembly)
- TypeScript 5.9, Vite 7, Vitest 3
- Web Audio API for all sound
- Barlow Condensed and Share Tech Mono typefaces (SIL OFL)

## Develop in the browser only

This project is developed without installing anything on your computer.

**Edit and run in StackBlitz:** open https://stackblitz.com/github/mekroket/operation-iron-veil. The `.stackblitzrc` file installs dependencies and starts the dev server inside the browser. Note that Babylon bugs can appear in the production bundle only, so a pass here is not final.

**Quick edits on GitHub:** press `.` on the repo page to open the web editor, or edit a file directly.

**Verify every change:**

1. Push to `main`.
2. GitHub Actions runs typecheck, tests and the production build, then deploys to GitHub Pages. See the repo's Actions tab.
3. Open the deployed URL. Add `?debug=1` for the `window.__ironveil` test API in `src/app/debugApi.ts`.

## npm scripts

For GitHub Actions and StackBlitz. Do not run these on your own machine.

| Script | Purpose |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run build` | Production build into `dist/` |
| `npm run preview` | Serve the production build |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | `vitest run` |
