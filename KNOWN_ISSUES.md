# Known issues: version 0.1

## Not verified

These items of the version 0.1 definition of done could not be exercised in the test environment. See `documentation/QA.md`.

- **Pointer lock and fullscreen on Start Mission.** The code follows browser rules and the refusal paths were tested, but the built-in browser pane refuses both, so success has never been observed.
- **StackBlitz preview.** The pane cannot run WebContainers. The GitHub Pages URL is the verified way to play. `.stackblitzrc` is in the repo, untested.
- **Real frame rate.** Frame cost was measured in a hidden pane; 60 fps at 1080p has not been observed.
- **Audio by ear.** Signal levels were measured. Nobody has listened, so mix and sound quality are untuned.
- **Human playtest.** No person has played this build. Mouse feel, difficulty and pacing are untested.
- **Mission length and difficulty.** A perfect-aim bot that never takes cover finished in 194 s with no deaths on one run, and 371 s with 11 deaths in the warehouse on another. The 10 to 15 minute target is unconfirmed, and the warehouse may be a difficulty spike.
- **WebGPU path (`?webgpu=1`).** Never run. WebGL2 is the tested path.
- **Cloudflare Pages.** The static build should deploy there (relative base path), but it is deployed on GitHub Pages only.

## Limitations

- **Procedural art.** All geometry and textures are generated by code. The look is stylised and does not reach photorealism. Characters and weapons are built from primitives and some surfaces read as plain blocks, such as the rear of the rifle.
- **No generated art in the game.** Higgsfield prompts are written in `documentation/HIGGSFIELD_ASSET_PROMPTS.md`, but nothing was generated, so no credits were spent. The menu background is the live 3D scene.
- **No GLB loader yet.** `@babylonjs/loaders` is a dependency and the path is documented in `documentation/ASSET_PIPELINE.md`, but no loader code exists.
- **Radio has no spoken voice.** Dialogue is subtitles over synthesised radio texture.
- **Enemy shadows can lag.** The sun shadow map redraws when the camera moves, not per frame, so shadows from moving enemies and doors may be out of date.
- **Enemy shots are probability rolls after a line-of-sight check,** not physical rays, and enemies do not collide with the player; they are pushed apart softly.
- **Local light selection for enemies and the gun is by player position,** because they share source meshes. An enemy far from the player may be lit by the wrong nearby fixtures.
- **Light changes can recompile shaders,** which may cause a brief hitch when crossing between lit areas. Not measured.
- **Dim interiors.** The east warehouse and the harbour office are dark, because lights per mesh are limited.
- **Exit.** Browsers only let a script close tabs it opened, so Exit usually shows a "safe to close this tab" screen.
- **After an Esc pause,** Chrome refuses to re-lock the pointer for about a second, so Resume may need one more click.
- **`?debug=1` is public.** It exposes the test API on the live site. This is a single-player game with nothing to protect, so it stays on.
